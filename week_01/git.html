Git & GitHub

1. Understand Git and GitHub

Both Git and GitHub are similar tools, but they are not the same. Git runs locally on your computer and doesn't require any internet connection to track file changes and save checkpoints locally.

GitHub on the other hand I like to think of as "social media" for coders. GitHub acts as a way to upload files and changes to the cloud to allow for collaboration and remote access. Ensuring that you utilize commit messages explaining any changes made to a file keeps you aware for your local files in Git, and any teammates or collaborators working on the same files in GitHub.

2. VS Code Source Control Process

My source control process in VS code is to I save all work locally while working. Once I've arrived at a stopping point I'll commit to git and include a commit message outlining the changes that were made during that commit. Once I'm satisfied, I'll then push that commit to GitHub to store remotely for myself or collaborators.
