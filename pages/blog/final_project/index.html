#

My Home Server Build

This is a showcase for the home server I built and run. This site walks through how it works, from the hardware to the security, in plain language. I am a big fan of the video game "Cyberpunk 2077" and uses a lot of helpful naming conventions that I adopted for my services. My servers named "Mikoshi", after a server in the game; "Blackwall" is what I named my Administrative panel that I use to monitor and manage the server.
